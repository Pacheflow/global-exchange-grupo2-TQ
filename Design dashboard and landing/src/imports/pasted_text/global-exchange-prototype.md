Diseña un prototipo completo de alta fidelidad para una plataforma web de casa de cambios llamada:

GLOBAL EXCHANGE

IMPORTANTE:
No quiero diseñar solamente una landing page ni solamente el Sprint 1.

Quiero visualizar desde ahora el PRODUCTO COMPLETO para poder navegarlo, probarlo, detectar problemas de UX y utilizarlo posteriormente como referencia para implementar el frontend real por etapas.

Sin embargo, dentro de la organización del archivo de Figma debe quedar identificado qué pantallas corresponden al Sprint 1 y cuáles pertenecen a etapas posteriores.

No mostrar al usuario final etiquetas como "funcionalidad futura" o "Sprint futuro". Esa diferenciación debe existir únicamente en la organización interna del archivo de diseño.

==================================================
1. OBJETIVO GENERAL
==================================================

Global Exchange es una plataforma web para digitalizar una casa de cambios.

El sistema completo contempla:

- usuarios;
- autenticación;
- roles y permisos;
- clientes;
- asociación usuario-cliente;
- selección de cliente activo;
- divisas;
- tasas de cambio;
- conversión de monedas;
- compra y venta de divisas;
- transacciones;
- pagos;
- facturación electrónica;
- ganancias;
- cajas virtuales;
- notificaciones;
- reportes;
- administración.

Quiero que la interfaz tenga apariencia de producto financiero profesional listo para producción.

Debe sentirse:

- seria;
- confiable;
- moderna;
- elegante;
- financiera;
- tecnológica;
- minimalista;
- ligeramente vintage/editorial;
- pero NO anticuada.

Tomar como referencia conceptual plataformas como Binance en:

- jerarquía visual;
- navegación;
- dashboards;
- tablas financieras;
- uso de datos;
- experiencia de usuario;
- modo oscuro;
- densidad de información.

NO copiar Binance literalmente.

Global Exchange debe tener identidad propia.

==================================================

La identidad principal de Global Exchange será DARK MODE.

- superficies ligeramente más claras que el fondo;
- bordes extremadamente sutiles;
- texto blanco;
- texto secundario gris;

Usar profundidad muy sutil mediante:

- capas;
- transparencias;
- bordes;
- sombras mínimas;
- contraste entre superficies.

LIGHT MODE:

- blanco;
- blanco azulado;
- gris muy claro;
- azul oscuro;

- textos casi negros o azul muy profundo.

62. REGLAS IMPORTANTES DEL SISTEMA
==================================================

Respetar estrictamente:

VISITANTE:
solo funciones públicas.

USUARIO AUTENTICADO SIN CLIENTE:
puede realizar consultas pero no comprar/vender.

USUARIO ASOCIADO:
opera sobre el CLIENTE ACTIVO.

VARIOS CLIENTES:
debe existir selección y cambio de cliente activo.

ADMINISTRADOR:
acceso administrativo según permisos.

ANALISTA:
tasas, análisis y ganancias.

CAJERO:
cajas y operaciones correspondientes.

El frontend debe ocultar acciones no permitidas.

La autorización real estará implementada posteriormente mediante backend + Keycloak.
